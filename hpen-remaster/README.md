# hPen Remaster — Windows 11

실행하면 현재 커서가 있는 모니터 위에 **테두리 없는 투명 필기층과 도구 모음**이 표시됩니다. 일반 프로그램 창에 바탕 화면을 가져오는 방식이 아닙니다. 기본 필기에서는 화면 캡처를 하지 않으므로 뒤의 영상과 프로그램은 그대로 움직입니다.

## 바로 실행

이 작업 폴더에서 `hPen.cmd`를 더블클릭합니다. 또는 PowerShell에서:

```powershell
cd C:\Users\user1\Documents\Codex\hpen-remaster
.\node_modules\electron\dist\electron.exe .
```

이전 버전이 실행 중이면 트레이 메뉴의 **종료**로 먼저 종료해야 수정 버전이 로드됩니다. 이때 저장하지 않은 필기는 사라집니다.

## 화면에 직접 필기

- 펜·직선·사각형·텍스트를 선택하고 화면 위에 바로 그립니다.
- 펜 자유곡선은 보정된 포인터 샘플과 곡선 보간을 사용해 빠르게 그어도 선이 부드럽게 이어집니다.
- 텍스트 위치를 클릭하면 그 자리에 포커스가 고정된 투명한 textarea가 나타납니다. 한글을 바로 입력하고 `Ctrl+Enter` 또는 바깥 클릭으로 확정하면 펜 모드로 돌아갑니다. 상단 **글자** 슬라이더나 입력 중 휠로 12~96px 크기를 조절할 수 있습니다. 작성된 텍스트를 다시 클릭하면 같은 자리에서 내용과 크기를 수정할 수 있습니다.
- **되돌리기 / 다시 실행 / 모두 지우기**로 수정합니다. 전체 지우기도 실행 취소할 수 있습니다.
- **앱 제어 모드**를 누르면 필기는 보존하고 클릭을 아래 프로그램으로 전달합니다. 상단의 **필기 모드** 버튼으로 바로 복귀합니다. 트레이 전환 메뉴도 사용할 수 있습니다.
- **숨김**은 필기층을 내용 그대로 숨깁니다. **Esc**는 필기를 지우고 닫습니다. Alt+백틱으로 다시 열면 빈 필기층이 나오며 Ctrl+R로 마지막 필기를 복구할 수 있습니다. 일반 제어 창은 나타나지 않습니다.
- **필기만 복사 / 필기만 PNG**는 배경 없이 투명 필기 이미지를 내보냅니다.
- 작업 표시줄과 트레이에 접근할 수 있도록 필기층은 모니터 작업 영역에 표시합니다.

## 같은 화면에서 돋보기

1. 투명 도구 모음의 **실시간 돋보기**를 누릅니다. 별도 일반 창 없이 같은 화면에 확대 장면이 표시됩니다.
2. 새 실행은 직접 필기와 **1×** 배율로 시작합니다. `Ctrl+휠`로 돋보기를 바로 시작하고 커서 주변을 1~10배 확대합니다. 실행 중에도 `Ctrl+휠`이나 배율 슬라이더로 조절하고 커서 추적을 끌 수 있습니다. 라이브 확대 화면에서는 원래 Windows 커서 대신 확대 화면 위에 선명한 민트색 원형 십자 커서를 표시하며, 상단 메뉴에서는 조작용 커서가 표시됩니다.
3. **멈춤 · 필기** 또는 Space로 장면을 고정한 뒤 필기합니다. 멈춘 상태에서는 일반 필기용 십자 커서가 표시되고, 백틱을 누르면 고정된 확대 화면과 그 위의 필기를 함께 영역 캡처할 수 있습니다.
4. **실시간 복귀** 또는 Space를 다시 누르면 확대 영상이 움직입니다. 다음 멈춤은 새 장면이므로 필요한 확대 필기는 먼저 복사·저장하세요.
5. **캡처 종료** 또는 Esc를 누르면 투명 직접 필기로 돌아오며, 돋보기를 켜기 전의 직접 필기도 복원되고 배율은 **1×**로 초기화됩니다. 필기 화면을 닫거나 숨겼다가 단축키로 다시 열 때도 항상 1×로 시작합니다.
6. 앱 제어 모드로 바꾸거나 설정·숨김으로 이동하면 확대 캡처를 중단합니다.

실시간 돋보기에는 화면 캡처 스트림이 필요합니다. 직접 필기는 이 스트림을 사용하지 않습니다. 확대 중에는 자기 자신을 다시 캡처하지 않도록 Windows 캡처 제외를 적용하고 직접 필기로 돌아오면 해제합니다. 화면 공유 프로그램에 미치는 영향은 환경별로 확인해야 합니다.

## 설정과 단축키

**설정** 버튼 또는 트레이 메뉴로만 설정 창을 엽니다. 여기서 모니터와 선택적 전역 단축키를 지정할 수 있습니다.

- 기본 **필기 모드 ↔ 앱 제어 모드** 전환 키는 **Alt+백틱** (Esc 아래의 백틱 키)입니다. 돋보기 전역 단축키는 기본 해제입니다. Alt+숫자·Windows 키·한영키를 가로채지 않습니다.
- 설정 입력 칸을 클릭하고 Ctrl·Shift·Alt와 문자·숫자·백틱·Space·F키 조합을 누른 뒤 **저장 · 적용**합니다. **해제** 후 저장하면 해당 단축키를 끕니다.
- 설정은 사용자 프로필의 `shortcuts.json`에 저장되어 다음 실행에도 유지됩니다. 등록 실패 시 안내하며 상단 전환 버튼은 계속 사용할 수 있습니다. 요청한 키는 다음 실행 때 다시 등록을 시도합니다.
- 필기 창의 Ctrl+Z/Y와 돋보기의 Space는 해당 창 내부에서만 처리합니다. 텍스트·입력 요소 편집 중에는 가로채지 않습니다.
- Esc로 숨긴 뒤에도 Alt+백틱을 누르면 필기층이 다시 열립니다. 표시된 상태에서는 필기 모드와 앱 제어 모드를 전환합니다.
- Alt+백틱은 누르는 시점에 **마우스 커서가 있는 모니터**에서 필기를 엽니다. 다른 모니터라면 필기층을 그 화면으로 옮기고 필기 모드로 전환합니다. 같은 모니터에서는 현재 모드를 전환합니다. 이동 중 돋보기는 종료하며 현재 직접 필기와 복구 내용은 유지합니다.
- Esc 처리 시 캔버스를 즉시 지우고 비운 프레임을 반영한 뒤 창을 숨깁니다. 다시 열 때 지우는 방식이 아닙니다. 마지막 내용은 Ctrl+R로만 복원합니다.
- 같은 모니터로 다시 열면 필기가 유지되지만 다른 모니터로 전환하면 필기층이 새로 생성됩니다. 먼저 필요한 필기를 저장하세요.

### 기존 필기 단축키

| 키 | 동작 |
|---|---|
| Q / W / E를 누른 채 드래그 | 사각형 / 원 / 직선 |
| R / F / G를 누른 채 드래그 | 역방향 / 정방향 / 양방향 화살표 |
| X / D / V를 누른 채 드래그 | X표 / 번개 / 곡선 |
| T | 텍스트 모드. 위치를 클릭해 바로 입력하고 Ctrl+Enter 또는 바깥 클릭으로 확정. 기존 텍스트 클릭 시 재편집 |
| 휠 / Ctrl+휠 | 필기 두께 조절 / 돋보기 시작 및 배율 조절 |
| Esc | 텍스트 모드 해제, 기본 모드에서는 필기를 지우고 닫기. Ctrl+R 복구 가능 |
| F1~F10 | 기존 기본 색상 순서로 변경 |
| Shift를 누른 채 필기 드래그 | 드래그 시작점에 걸린 필기 객체 이동 |
| C / Ctrl+R | 모두 지우기 / 마지막 작성 내용 복원 |
| Ctrl+Z / Ctrl+Y / Ctrl+S | 실행 취소 / 다시 실행 / PNG 저장 |
| Alt+숫자패드 0~9 / 숫자패드 0~9 | 필기 메모리 저장 / 불러오기 |

도형 단축키를 누르면 상단 도구 모음의 선택 표시도 해당 도형으로 바뀌고, 키를 놓으면 원래 선택한 도구로 돌아갑니다. Shift 이동은 선·도형·자유곡선·텍스트에 적용되고 겹친 필기는 함께 이동하며 Ctrl+Z/Y로 실행 취소·다시 실행할 수 있습니다. 텍스트 편집 중에는 한글·Space·문자 키를 필기 명령으로 처리하지 않습니다. OS 한영 전환은 기존 Windows 입력기를 사용하며, 투명 입력기에는 번지는 그림자 없이 밝은 커서만 표시합니다. 현재 메모리 슬롯은 필기 객체를 보관하며 배경 화면까지 저장하는 기존 슬롯 기능은 아직 지원하지 않습니다.

F1~F10은 필기 모드에서만 적용하며 앱 제어 모드·텍스트 모드·설정에서는 색상을 바꾸지 않습니다. 기존 색상 순서는 검정, 빨강, 파랑, 노랑, 초록, 주황, 하늘, 분홍, 보라, 흰색입니다. F키를 전역으로 등록하지 않습니다.

## 개발 환경

Electron + TypeScript + Canvas 2D. UI는 현재 HTML/CSS이며 React는 아직 사용하지 않습니다.

Node.js와 npm을 설치한 환경:

```powershell
npm install
npm run setup
npm run check
npm test
npm start
```

`npm run pack`은 Windows x64 실행 폴더를 만듭니다. 서명된 설치 프로그램은 아닙니다.

포터블 EXE와 설치 프로그램을 만들려면 `build-windows.cmd`를 실행하세요. 개별 제작은 `npm run build:portable`, `npm run build:installer`입니다. 자세한 절차와 출력 파일은 [BUILDING.md](BUILDING.md)를 참고하세요.

## 영역 캡처

상단의 **캡처** 버튼을 누르면 커서가 있는 모니터의 밝기를 바꾸지 않고 영역을 드래그할 수 있습니다. Esc로 취소합니다. 어느 방향으로 드래그해도 동일하게 처리하며 선택 테두리는 결과 이미지에 들어가지 않습니다.

- **필기 모드에서 백틱 단독**을 누르거나 상단 **캡처** 버튼을 누르면 상단 메뉴와 상태 문구만 숨긴 채 화면을 읽고 현재 필기 캔버스를 합성합니다. 같은 필기 창 위에는 배경을 다시 그리지 않는 완전 투명 선택 레이어만 올라가므로 전체 화면 깜빡임이나 별도 창 전환이 없습니다. 결과 PNG와 클립보드 이미지에는 필기가 들어가고 도구 모음은 포함되지 않습니다.
- **Ctrl+백틱**은 앱 제어 모드·숨김 상태에서도 실행되는 전역 캡처이며, 원래 화면만 캡처합니다.

선택을 마치면 이미지를 **클립보드에 자동 복사**하고 Windows의 **사진/hPen** 폴더에 시간 기반 이름의 PNG로 **동시에 저장**합니다. 두 작업 중 저장이 실패하면 오류를 표시하고 다시 시도할 수 있습니다. 전역 캡처 전에는 필기층·설정 창을 잠시 숨겨 원래 화면을 캡처합니다. Ctrl+백틱은 설정에서 변경·해제할 수 있으며, 캡처 후에는 실행 전 모드로 돌아갑니다.

## 검증

- TypeScript 검사·번들 빌드 통과.
- 화면 경계 확대 좌표와 정규화 좌표 단위 테스트 2개 통과.
- Electron `--smoke-test` 앱 통합 검사 15개 통과: 기본 투명 필기층, Alt+백틱 기본값·실제 OS 등록·해제 및 재등록, 획 표시, undo/redo, 동일 필기층에서 실시간 캡처, 멈춤·내보내기 활성화, 실시간 복귀, 종료 후 원래 필기 복원, 클릭 통과 모드 전환, 상단 복귀 버튼, 36px 한 줄 도구 모음.
- 통합 검사는 별도 프로필로 잠시 실행하고 종료하며 결과를 `smoke-result.json`에 씁니다. 테스트 필기는 저장하지 않습니다.

## 남은 수동 확인과 제약

- 실제 투명도와 필기 지연, 다른 앱으로 클릭 전달/복귀.
- 다른 배율의 듀얼 모니터, 음수 좌표, 모니터 배율/작업 영역 변경.
- 자기 화면 반복 캡처 여부, 캡처 제외 창 뒤의 화면, 화면 공유 포함 여부.
- 한글 IME 조합·붙여넣기·텍스트 완료, 펜 입력, 빠른 연속 전환.
- 장시간 메모리 사용과 100회 이상 반복 사용, 절전 복귀.
- 보호 콘텐츠·보안 데스크톱·독점 전체 화면 위 표시는 보장하지 않습니다.
- 프로젝트 저장·페이지 이력과 이동 외 객체 선택 편집은 후속 기능입니다. 현재 필기와 이력은 앱 종료 시 사라집니다.

도구 모음은 상단 36px 높이의 한 줄입니다. 앱 제어 모드에서도 도구 모음 위에서는 클릭을 받고 나머지 화면은 아래 앱으로 전달합니다. 좁은 화면에서는 한 줄 가로 스크롤을 사용합니다.
