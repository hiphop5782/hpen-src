# 작업 내역

## 조사와 설계

- 기존 Java/JNA hPen의 기능, 키보드 차단, 자체 한글 조합, 캡처·확대 구조 분석.
- Windows 11 정상 작동을 최우선으로 정하고 Electron + TypeScript + Canvas 2D 채택.
- 조사 보고서: `HPEN-REVIEW.ko.md`, 기능 개선 보고서: `HPEN-FUNCTIONAL-IMPROVEMENTS.ko.md`. 보고서의 초기 권장 스택·구현 순서는 당시 조사 기록이며 현재 구현은 아래 내용을 따른다.

## 구현

- 일반 창이 아닌 화면 위 투명 필기층으로 시작. 상단 36px 한 줄 도구 모음.
- 필기 모드와 앱 제어 모드 전환. 앱 제어 중에도 도구 모음의 필기 모드 버튼은 클릭 가능.
- 전환 기본 키 **Alt+백틱**, 영역 캡처 기본 키 **Ctrl+백틱**. 설정에서 변경·해제 및 다음 실행까지 저장. 이전 기본 Ctrl+Space 및 Ctrl+백틱/Shift+백틱 기본 설정은 새 기본값으로 이동.
- 전환 키를 누른 순간 커서가 있는 모니터로 필기층 이동.
- Esc는 즉시 캔버스를 지운 후 숨김. 다시 열면 빈 화면, Ctrl+R로 마지막 필기 복구.
- 기존 도형 키 Q/W/E/R/F/G/X/D/V를 누른 채 드래그하는 방식 유지. 누르는 동안 상단 선택 표시도 해당 도형으로 동기화하고 키를 놓으면 원래 도구 표시로 복귀. T 텍스트, C 지우기, Ctrl+Z/Y/S/R 유지.
- Shift를 누른 채 필기를 드래그하면 시작점에 걸린 선·도형·자유곡선·텍스트를 이동. 겹친 필기는 함께 이동하고 undo/redo 지원.
- 일반 휠은 필기 두께를 조절하고 Ctrl+휠은 돋보기를 시작해 배율을 조절. 텍스트는 클릭 지점의 투명 textarea에 클릭 기본 동작 이후까지 포커스를 재고정해 작성하며 Ctrl+Enter 또는 바깥 클릭으로 확정 후 펜 모드 복귀. 상단 슬라이더와 입력 중 휠로 12~96px 글자 크기 조절, 기존 텍스트 내용·크기 재편집과 undo/redo 지원. 입력 중에도 확정된 글자처럼 선명하게 보이도록 번지는 대비 그림자는 사용하지 않고 밝은 커서만 적용.
- 펜 자유곡선은 coalesced pointer 샘플을 빠짐없이 수집하고 중간점 이차 곡선으로 보간해 빠른 입력의 끊김과 각짐을 완화.
- F1~F10 기존 색상과 순서 유지. 필기 모드에만 적용하고 앱 제어 모드·텍스트 모드에서는 적용하지 않음.
- 숫자패드 메모리 10개 슬롯. 현재 슬롯은 필기 객체만 보관.
- 새 실행은 돋보기 스트림 없이 직접 필기와 1× 배율로 시작. 실시간 돋보기 1~10배, 커서 추적, Space 멈춤·실시간 복귀. 라이브 확대 영역은 원래 Windows 커서 대신 확대 캔버스 위의 별도 DOM 층에 고대비 민트색 원형 십자 커서를 표시하고, 멈춤 상태는 필기용 커서를 복원해 필기와 백틱 영역 캡처를 허용. Esc·종료 버튼·필기 닫기/숨김 뒤 재시작 모두 직접 필기로 복귀하고 배율을 1×로 강제 초기화.
- 영역 캡처 선택 화면, 역방향 드래그 및 DPI 좌표 변환. 클립보드 복사와 사진/hPen PNG 파일 저장을 함께 수행. Esc 취소.
- 캡처는 필기 모드·앱 제어 모드·숨김 상태에서 전역 키로 시작 가능. 완료·취소 후 이전 상태 복원.
- 필기 모드의 백틱 단독 및 상단 캡처 버튼은 상단 메뉴·상태 문구만 숨기고 화면과 현재 필기 캔버스를 백그라운드에서 합성. 합성 전체 이미지를 먼저 메인 프로세스에 확정해 DPI 선택 크기 불일치를 막고, 같은 필기 창 위에는 배경을 그리지 않는 투명 영역 선택 캔버스만 표시. Windows 캡처 제외 속성 토글과 별도 창 전환을 사용하지 않아 전체 화면 깜빡임을 제거하고 저장·클립보드 결과에 필기를 포함. Ctrl+백틱 전역 캡처는 기존처럼 원래 화면만 처리.
- 영역 선택은 전체 화면을 어둡게 하지 않고 원본 밝기를 유지하며 민트색 테두리로만 범위를 표시. 별도 선택 창을 만들지 않아 작업 표시줄 중복과 화면 전환 효과를 제거.
- 투명 필기 PNG 내보내기, 확대 화면 PNG·클립보드 내보내기.
- 기존 강아지 트레이 아이콘 재사용. 설치 파일용 아이콘은 동일 원본을 규격에 맞춰 변환.

## 실행·배포

- `hPen.cmd`: 의존성이 설치된 개발 폴더에서 바로 실행.
- `build-windows.cmd`: 의존성 설치, 검사·테스트, 포터블 및 NSIS 설치 EXE 제작.
- `npm run pack`, `build:portable`, `build:installer`, `build:win` 제공.
- 제작 방법은 `BUILDING.md` 참고. Windows x64, 사용자 권한 실행, 사용자별 설치.
- 서명 인증서는 포함하지 않음. 자동 업데이트와 정식 배포 서명은 아직 구현하지 않음.

## 검증과 남은 사항

- TypeScript 검사, 번들 빌드, 좌표·단축키·캡처 단위 테스트 통과.
- 별도 테스트 프로필로 투명 필기·도형·색상·Esc 즉시 삭제·복구·모니터 이동·돋보기·캡처 PNG/클립보드 처리 통합 검사.
- 최종 UI 사용감, 장시간 사용, 다양한 배율·펜 장치·전체 화면 앱, 화면 공유와 캡처 제외 동작은 추가 수동 검증 필요.
- 프로젝트 파일, 페이지 관리, 객체 선택 편집, 배경까지 포함한 메모리 슬롯은 후속 작업.
- 원래 한영키를 차단하지 않고 OS IME를 사용. 전역 저수준 키보드 후킹을 추가하지 않음.

## 저장소 반영 범위

소스·원본 아이콘·문서·테스트·빌드 스크립트와 잠금 파일을 반영한다. `node_modules`, `dist`, `release`, npm 캐시, 테스트 프로필, 실제 화면 캡처 이미지는 업로드하지 않는다. 실행·설치 파일은 스크립트로 재생성할 수 있다.
